# Shofe

AI montaža za Markove reelove, Sunčani4M podcast i isječke za mreže. Snimaš, kažeš što želiš, Shofe montira.

- **Što Shofe radi i što će raditi:** `SPEC.md`
- **Napredak:** `ROADMAP.md` (zadaci) i `DNEVNIK.md` (što je agent radio)
- **Odluke s razlozima:** `ODLUKE.md`
- **Alat za instalaciju:** mapa `shofe-montaza/` (upute u njezinom `README.md`; na Windowsu dvoklik na `INSTALIRAJ.bat`)

Razvija ga Claude agent koji radi sam svaka 2 sata (upute: `CLAUDE.md`). Pitanja za Marka su u GitHub issues s oznakom `za-marka`. Prave testne klipove (do 25 MB) stavi u `tests/real/`.
